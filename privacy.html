Privacy Policy

Last Updated: March 1, 2026

Overview

Cueit helps users remember checklist items when arriving at saved locations. We design Cueit to minimize data collection and keep user information private.

Information We Process

  • Account authentication data via Firebase Authentication and selected sign-in providers.
  • Location data on device for geofence reminders.
  • User-created checklist content stored locally on device.

How Data Is Used

  • Authenticate and maintain user session.
  • Trigger reminder notifications for saved locations.
  • Display and manage user checklist content.

Data Sharing

We do not sell user data. We do not run analytics tracking in Cueit. Authentication requests are handled by authentication providers.

Storage & Retention

Checklist data is stored locally on the device. Data remains until deleted by the user or app removal. iCloud backup behavior depends on user iOS settings.

User Controls

  • Revoke location permissions in iOS Settings.
  • Delete account session and local app data from app settings.

Contact

For privacy questions, contact: support@cueitapp.com
